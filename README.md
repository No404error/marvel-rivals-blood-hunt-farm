# 漫威争锋 · 血猎自动挂机

**语言 / Language:** [中文](README.md) | [English](README.en.md)

这是一个 **[ScreenFlow](https://github.com/No404error/screenflow-studio)** 项目实例：用前台截屏 + 模板匹配，在《漫威争锋》**血猎**模式下自动循环开局、清装备、选人、局内按 F、结算回主页。

本仓库**只包含项目配置与识别图**，不包含引擎。运行请使用 ScreenFlow Studio。

---

## 重要：当前资源为简体中文客户端

仓库内的 `pages/` 识别图、点击图以及文案相关匹配，均按 **简体中文** UI 采集。

- 若你使用 **英文（或其它语言）客户端**，**不能直接套用**这些图片与部分状态条件。  
- 请对照下方「挂机逻辑」，在 Studio 中**自行重新配置页面、情况（状态树）、识别图 / 点击图**等资源后再运行。  
- 分辨率差得较远或 UI 改版后，同样需要重新截取资源并在 Studio 中配置。

---

## 它做什么（挂机逻辑）

在游戏保持前台时，大致循环：

1. 主页点击开始游戏  
2. 若装备过多：角色培养 → 锻炉 → 全选 → 熔炼 → 确认奖励后回主页  
3. 选人：有索尔则确定；没有则先点索尔再确定  
4. 局内：右下角 F 为「待使用」时按 F  
5. 结算：跳过 → 回主页 → 再开一局  

不是读内存、不是注入；游戏不在前台时无法可靠运行。

## 前置条件

开始前请同时满足以下条件（本项目**不会**自动切换模式或难度）：

| 类别 | 条件 |
|------|------|
| 软件 | 已安装并可启动 [ScreenFlow Studio](https://github.com/No404error/screenflow-studio)（Windows） |
| 系统 | 运行引擎时可能需要 **管理员权限**（UAC 允许） |
| 游戏模式 | 主页已手动选好 **血猎** |
| 难度 | **噩梦 1**（Nightmare 1） |
| 队伍 | **单人**（不要组队 / 匹配补齐队友） |
| 客户端语言 | **简体中文**（与仓库资源一致；其它语言须自行重配资源） |
| 分辨率 | 本项目资源基于 **2560×1440** 截图；若你的分辨率差得较远，需自行重新截取识别图 / 点击图，并在 Studio 中重新配置 |
| 运行时 | 游戏窗口保持**前台**；英雄倾向 **索尔**（选人逻辑按索尔编写） |

不满足难度 / 模式 / 语言时，识别与流程很容易失败。

## 怎么用

### 1. 安装并启动 ScreenFlow

从引擎仓库获取并启动 Studio：

- 仓库：[No404error/screenflow-studio](https://github.com/No404error/screenflow-studio)  
- 源码示例：`python .\run_studio.py`  
- 或使用其发布包中的 `ScreenFlow.exe`

### 2. 打开本项目

在 Studio 中：**文件 → 打开项目文件夹…**，选择**本仓库根目录**（含 `project.json` 与 `pages/` 的那一层）。

### 3. 核对前置条件

确认上一节「前置条件」均已满足（尤其是 **血猎 + 噩梦 1 + 单人 + 简体中文**）。

### 4. 开始挂机

1. 确认资源语言与客户端一致（非中文请先重配）  
2. 在 Studio 中按需微调运行参数后 **保存**  
3. 点击 **开始**（首次可能弹出 UAC，需允许引擎提权）  
4. 用暂停 / 继续 / 停止控制运行
