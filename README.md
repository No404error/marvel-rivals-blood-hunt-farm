### 它能做什么

在游戏**前台**、**管理员权限**下自动循环：

1. 主页点击「开始游戏」
2. 选人：有「索尔」则点「确定」；没有则先选索尔再确定；已是「取消」则等待进图
3. 局内：仅当右下角 **F 为「待使用」** 时按 F
4. 结算：长按空格跳过 → ESC 回主页 → 再开一局

不是读内存、不是注入，也不支持游戏在后台时挂机。

### 使用前请满足

| 项目 | 要求 |
|------|------|
| 模式 | 主页**手动选好「血猎」**（工具不会帮你切模式） |
| 难度 | **噩梦 1** |
| 队伍 | **最好单人**（不要组队 / 匹配补齐队友） |
| 英雄 | **索尔**，走**符文觉醒**流派 |
| 觉醒时长 | **持续时间要长**（如优先「不灭符文」等），保证挂机能覆盖波次 |
| 伤害 / 生存 | **足够高**，避免清不动怪或被打死（工具不会走位、治疗） |
| 系统 | Windows |
| 权限 | **必须管理员运行**（会弹 UAC） |
| 窗口 | 游戏在前台、不被遮挡 |
| 分辨率 | 建议接近 **2560×1440**（参考 2559×1439） |
| 客户端 | 当前识别模板面向**简体中文**界面 |

### 下载与使用（推荐）

1. 打开本仓库的 **[Releases](../../releases)** 页面  
2. 下载最新版本的压缩包（如 `marvel-rivals-blood-hunt-farm-v*.zip`）并解压  
3. 运行 **`auto_farm.exe`**（必须在 UAC 中选择「是」）  
4. 先切到游戏窗口；启动后约 3 秒开始自动操作  

快捷键：

| 键 | 功能 |
|----|------|
| F9 | 开始 / 继续 |
| F10 | 暂停 |
| F11 | 退出 |

---

### 从源码运行（可选）

若你更想用 Python 而不是 exe：

```powershell
pip install -r requirements.txt
# 必须用「以管理员身份运行」的终端
python .\auto_farm.py
```
